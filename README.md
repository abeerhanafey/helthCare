# Pharaoh AI — HealthCare Companion

واجهة ويب عربية/إنجليزية للتثقيف الصحي والعناية اليومية، بهوية مستوحاة من الحضارة المصرية القديمة.

## محتويات المجلد
- `index.html` — بنية الموقع والصفحات.
- `style.css` — التصميم المتجاوب وهوية Pharaoh AI.
- `app.js` — التفاعلات المحلية، المساعد التثقيفي، قاموس المكونات، ومحتوى الحالات.
- `assets/` — مجلد مخصص لإضافة الصور والأيقونات لاحقًا.

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` باستخدام Chrome أو Edge.
3. لا يحتاج الموقع إلى تثبيت حزم أو تشغيل خادم في نسخته الحالية.

## الوظائف
- لوحة متابعة العادات اليومية والملف الصحي التجريبي.
- معلومات تغذية تثقيفية حسب حالات صحية مختارة.
- روتين عناية مبدئي حسب نوع البشرة.
- فاحص نصي تعليمي لمكونات عناية شائعة.
- مساعد Pharaoh AI محلي بردود وقواعد معرفة محدودة.
- مكتبة ودليل للحالات الصحية.
- دعم العربية والإنجليزية والوضع الليلي.

## حدود مهمة
هذه نسخة Frontend تعليمية وليست خدمة طبية:
- المساعد غير متصل بنموذج ذكاء اصطناعي خارجي؛ الردود محلية ومحدودة.
- لا يشخّص ولا يصف أدوية أو جرعات ولا يصمم حمية علاجية شخصية.
- معلومات الأمراض والتغذية عامة؛ الحالات المزمنة تحتاج خطة من الفريق الطبي.
- فاحص المكونات لا يقرأ صور العبوات ولا يثبت السلامة أو الحساسية أو ملاءمة المنتج.
- لا تدخل بيانات طبية حقيقية أو حساسة؛ لا توجد قاعدة بيانات آمنة.
- يلزم مراجعة المحتوى من مختصين ومصادر طبية موثوقة قبل أي إطلاق عام.

## متطلبات النسخة الإنتاجية
Backend آمن، مصادقة وتشفير، ربط AI من جهة الخادم فقط، قاعدة معرفة موثقة ومراجعة سريريًا، OCR للملصقات مع تأكيد النص، واختبارات خصوصية وأمان وإتاحة.
