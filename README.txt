# HealthCare Companion — Demo

A responsive, Arabic-first healthcare wellness website built with vanilla HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and sections
- `style.css` — responsive styling, light/dark themes
- `app.js` — navigation, demo profile, trackers, ingredient text checker, and demo chat

## Run
Open `index.html` in a modern browser. No build step is required.

## Important limitations
- This is a front-end educational demo, not a medical service or certified medical device.
- The assistant is a scripted demo. It is NOT connected to a live AI model.
- Profile information and trackers exist only in page memory for the current session; they are not securely stored or sent to a server.
- Ingredient checking is a simple text match and cannot assess allergy safety or guarantee product safety.
- Product URL retrieval, authentication, database storage, notifications, and backend AI integration are not implemented.
- Do not enter real medical records or sensitive personal information.
- Any real deployment requires a secure backend, privacy/security review, reliable medical content sources, and qualified clinical review.
